1. MODELO DE PRIMER ORDEN

H(s) = K / (1 + τs)
Datos obtenidos
K = 0.992
τ = 8.30 s
H(s) = 0.992 / (1 + 8.30s)
Polo
1 + τs = 0 → s = −1/τ
sₚ = −1/8.30 = −0.1205 s⁻¹
Ceros
El numerador es K, una constante → no hay ceros finitos.

2. OBTENCIÓN DE τ

ΔT = Tf − T0
Tτ = T0 + 0.637(Tf − T0)
Ejemplo
T0 = 25 °C · Tf = 70 °C
Tτ = 25 + 0.637(70 − 25) = 53.67 °C
Lectura experimental
Cuando LM35 alcanza Tτ: τ = 8.30 s.
τ se obtiene de la respuesta transitoria experimental, usando el punto del 63.7 %.
